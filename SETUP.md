# T2 Docker setup

## Prerequisites and fresh workspace

Install Docker Desktop (running, with Compose), Git, and a POSIX shell. Network
access to GitHub and the image/package registries used by `build.sh` is required.
Obtain this **spike workspace bundle** from the maintainer who supplied this
runbook; the spike utilities are not part of the upstream container repository.
Use `<bundle-dir>` below for the directory containing that bundle.
Do not assume cloning the upstream repository supplies the following inputs:

| Required input | Source / purpose |
| --- | --- |
| `SETUP.md` | This bundle's runbook; copy to the fresh workspace root. |
| `utils/compose.step4-no-crl.yaml` | Bundle; disables CRL-L3 on both services, retaining mTLS. |
| `utils/t2-spike-profile.json` | Bundle; clean three-marker profile. |
| `utils/t2-spike-event.c` | Bundle; event sender source. |
| `utils/t2-prepareHttpUrl-fix.diff` | Bundle; JSON HTTP initialization patch. |
| `utils/apply-t2-patch.sh` | Bundle; isolated normal/ASan installer. |
| `telemetry/` | Clone `https://github.com/rdkcentral/telemetry.git` at revision `a2f2a545e4bd6170eac96f7c0c46fbd4df6f1654`. |
| `utils/t2-spike.log` | Generated by the marker command below; do not copy old logs. |
| `shared_certs/` | Generated during fresh container startup; do not copy old certificates. |

Create `<bundle-dir>/fresh-run`, copy only SETUP.md and
the five listed utility files from the bundle into matching paths, and run all
commands below from that fresh workspace root.
The linked EVIDENCE.md, SAMPLES.md, WRITEUP.md and upstream issue drafts are
optional historical reading, not setup inputs. Do not copy old build trees,
profiles, receipt logs, credentials, or container backups.

## Build and verification

```sh
# Clone and build (new workspace; Docker Desktop must be ready).
GIT_TERMINAL_PROMPT=0 git clone https://github.com/rdkcentral/docker-device-mgt-service-test
GIT_TERMINAL_PROMPT=0 git clone https://github.com/rdkcentral/telemetry.git
git -C telemetry checkout --detach a2f2a545e4bd6170eac96f7c0c46fbd4df6f1654
(cd docker-device-mgt-service-test && GIT_TERMINAL_PROMPT=0 ./build.sh)
# Compose up: retain mTLS; disable CRL-L3 on both services.
# For certificate renewal, stop T2 first (SIGKILL if SIGTERM hangs), then:
# docker compose -f docker-device-mgt-service-test/compose.yaml -f utils/compose.step4-no-crl.yaml down
docker compose -f docker-device-mgt-service-test/compose.yaml -f utils/compose.step4-no-crl.yaml up -d --pull never mock-xconf l2-container
docker compose -f docker-device-mgt-service-test/compose.yaml -f utils/compose.step4-no-crl.yaml ps
# Wait for initial certificate exchange; require collector listen and native CA import.
docker logs --tail 60 native-platform
docker logs mockxconf 2>&1 | grep 'Data Lake Mock Server running'
# Require the RFC provider and its data-model parameter before continuing.
docker exec native-platform pgrep -a rtrouted
docker exec native-platform pgrep -a rfc_provider
docker exec native-platform rbuscli getvalues Device.X_RDK_WebConfig.webcfgSubdocForceReset
# Re-export the current public server CAs, then refresh trust without native regeneration.
docker exec mockxconf sh -c 'cp /etc/pki/Test-RDK-root/certs/Test-RDK-root.pem /mnt/L2_CONTAINER_SHARED_VOLUME/shared_certs/server/root_ca.pem; cp /etc/pki/Test-RDK-root/Test-RDK-server-ICA/certs/Test-RDK-server-ICA.pem /mnt/L2_CONTAINER_SHARED_VOLUME/shared_certs/server/intermediate_ca.pem'
docker exec -e ENABLE_MTLS=false -e ENABLE_CRL_L3=false native-platform /usr/local/bin/certs.sh
docker exec native-platform curl --fail --show-error --connect-timeout 5 --max-time 15 --cert /opt/certs/client.pem --key /opt/certs/client.pem https://mockxconf:50051/dataLakeMockReportProfile
# Fresh container only: preserve original installed artifacts before patching.
# Refuse to overwrite an existing backup or copy libraries from a running T2.
docker exec -i native-platform python3 - <<'PY'
import pathlib, shutil, json, hashlib, subprocess
if subprocess.run(['pgrep', '-x', 'telemetry2_0']).returncode == 0:
    raise SystemExit('Stop T2 before creating the original backup')
root = pathlib.Path('/opt/t2-orig')
if root.exists():
    raise SystemExit('Original backup already exists; do not overwrite it')
names = ['libt2utils', 'libdcautil', 'librbusmethod', 'libbulkdata',
         'libccspinterface', 'libreportgen', 'libscheduler', 'libhttp',
         'libt2parser', 'libxconfclient', 'libtelemetry_msgsender']
files = [pathlib.Path('/usr/local/bin/telemetry2_0')]
for name in names:
    files.extend(pathlib.Path('/usr/local/lib').glob(name + '.*'))
manifest = []
for src in files:
    dst = root / src.relative_to('/')
    dst.parent.mkdir(parents=True, exist_ok=True)
    shutil.copy2(src, dst, follow_symlinks=False)
    manifest.append({'path': str(src),
                     'link': str(src.readlink()) if src.is_symlink() else None,
                     'sha256': hashlib.sha256(src.read_bytes()).hexdigest()})
(root / 'manifest.json').write_text(json.dumps(manifest, indent=2))
print('BACKUP', len(manifest), 'artifacts')
PY
# Install only with T2 stopped and the preserved original backup present.
sh utils/apply-t2-patch.sh normal
# Launch only if absent; preserve a running daemon.
if ! docker exec native-platform pgrep -x telemetry2_0 >/dev/null; then
  docker exec -d native-platform sh -c "trap '' PIPE; exec /usr/local/bin/telemetry2_0"
fi
sleep 3
docker exec native-platform pgrep -a telemetry2_0
# Load the clean profile and allow asynchronous registration.
docker exec native-platform sh -c 'rbuscli setvalues Device.X_RDKCENTRAL-COM_T2.ReportProfiles string "$(cat /mnt/L2_CONTAINER_SHARED_VOLUME/utils/t2-spike-profile.json)"'
sleep 5
# Trigger grep, data-model and event markers before the next 30-second deadline.
printf 'SPIKE_MATCH runbook\n' >> utils/t2-spike.log
docker exec native-platform rbuscli setvalues Device.X_RDK_WebConfig.webcfgSubdocForceReset string true
docker exec native-platform rbuscli getvalues Device.X_RDK_WebConfig.webcfgSubdocForceReset
docker exec native-platform gcc -I/usr/local/include /mnt/L2_CONTAINER_SHARED_VOLUME/utils/t2-spike-event.c -L/usr/local/lib -Wl,-rpath,/usr/local/lib -ltelemetry_msgsender -o /tmp/t2-spike-event
docker exec native-platform /tmp/t2-spike-event
sleep 35
# Require all three markers in ONE collector body, plus HTTP 200 and the same PID.
docker logs --timestamps --since 1m mockxconf 2>&1 | grep 'Data received:'
docker exec native-platform sh -c 'grep "Report Sent Successfully" /opt/logs/telemetry2_0.txt.0 | tail -3; pgrep -a telemetry2_0'
# Verify three additional reporting cycles without replacing the daemon.
T2_PID=$(docker exec native-platform pgrep -x telemetry2_0)
for cycle in 1 2 3; do
  sleep 35
  test "$(docker exec native-platform pgrep -x telemetry2_0)" = "$T2_PID" || { echo "FAIL: PID changed"; break; }
  docker logs --timestamps --since 35s mockxconf 2>&1 | grep 'Data received:'
done
# Outage: record network, collector start, PID, hashes and cache first.
docker inspect --format '{{json .NetworkSettings.Networks}} {{.State.StartedAt}}' mockxconf
docker exec native-platform sh -c 'pgrep -a telemetry2_0; sha256sum /opt/certs/client.pem /opt/certs/client.p12; if [ -d /opt/.t2cachedmessages ]; then ls -la /opt/.t2cachedmessages; else echo "No cache directory yet"; fi'
NET=docker-device-mgt-service-test_default
# Always reconnect, including on interruption; retain the collector DNS aliases.
trap 'docker network connect --alias mockxconf --alias mock-xconf "$NET" mockxconf' EXIT HUP INT TERM
docker network disconnect "$NET" mockxconf
sleep 65
docker exec native-platform sh -c 'grep -E "curl failed|Report Cached" /opt/logs/telemetry2_0.txt.0 | tail -12; ls -la /opt/.t2cachedmessages'
docker network connect --alias mockxconf --alias mock-xconf "$NET" mockxconf && trap - EXIT HUP INT TERM
sleep 40
# Require cache growth during outage, HTTP 200/replay, matching CACHED receipts, empty cache.
docker exec native-platform sh -c 'grep -E "Trying to send|Report Sent Successfully" /opt/logs/telemetry2_0.txt.0 | tail -18; ls -la /opt/.t2cachedmessages'
docker logs --timestamps --since 3m mockxconf 2>&1 | grep 'Data received:'
# Cleanup: restore mock false, retain daemon, credentials, cache evidence and containers.
docker exec native-platform rbuscli setvalues Device.X_RDK_WebConfig.webcfgSubdocForceReset string false
docker exec native-platform rbuscli getvalues Device.X_RDK_WebConfig.webcfgSubdocForceReset
docker exec native-platform sh -c 'pgrep -a telemetry2_0; sha256sum /opt/certs/client.pem /opt/certs/client.p12'
docker inspect --format '{{.State.StartedAt}}' mockxconf
```

## Pre-demo check

Certs are valid for 1 day from container start. Recreate the containers within ~20 hours before a demo. -checkend 7200 must pass (2-hour margin).

Run both commands before any demo. Exit 0 means the certificate will not expire
within the next 2 hours; exit 1 means it will (not necessarily expired now).
Check `-dates` and `-checkend 0` as well; never bypass TLS verification.

```sh
docker exec native-platform openssl x509 -in /opt/certs/client.pem -noout -checkend 7200
docker exec mockxconf openssl x509 -in /etc/xconf/certs/mock-xconf-server-cert.pem -noout -checkend 7200
```

## Known issues

- Fresh startup requires `ENABLE_CRL_L3=false` on **both** services. Disabling
  only the collector leaves native startup waiting for an unexported CRL
  certificate and eventually aborting. The bundle override covers both;
  `ENABLE_MTLS=true` remains inherited from upstream Compose.
  [CRL-L3 startup mismatch evidence.](EVIDENCE.md#step-4-collector-only-crl-l3-override)
- The fresh upstream image at container repository revision
  `89c43d241418d15a23d3555aaa94c1c8ff7dec16` logs a missing
  `/usr/local/bin/tr69hostif`. RBUS, `rfc_provider`, and the required
  `Device.X_RDK_WebConfig.webcfgSubdocForceReset` parameter were independently
  verified working. Image export alone is not a full-stack build validation:
  `build.sh` and nested build scripts can mask failures.
- If correcting startup requires recreating native-platform, its initial client
  credentials change. Before launching T2, let native export its new public
  client CA chain, restart mockxconf to import that chain, then repeat the public
  server-CA export and `ENABLE_MTLS=false ENABLE_CRL_L3=false` trust-refresh
  command above. Do not recreate either service during PID/outage acceptance.
- [Collector restart consumes public client-chain export; re-export existing chain only.](EVIDENCE.md#restarting-mockxconf)
- [XConf lacks DeviceInfo/ConfigURL provider; JSON loading is the tested path.](EVIDENCE.md#step-5-bounded-xconf-investigation)
- [Installer needs stopped T2 and preserved `/opt/t2-orig/`; the fresh-container backup command above supplies it.](EVIDENCE.md#step-10-patched-http-parser)
- Fresh-clone runtime status: Step 16 passed the documented post-build path in
  `fresh-run/` after both-container recreation: all-marker receipt, **20/20**
  receipts in ten minutes, and one successful outage replay with an empty cache.
  See [current results](EVIDENCE.md#step-16-final-verification).
  This does not establish a successful full `build.sh` or cross-architecture repeatability.
- [Keep the tested SIGPIPE-ignore wrapper; original exit signal remains unconfirmed.](EVIDENCE.md#step-11-sigpipe-ignore-launch)
- [ReportTimestamp parses but emits no report-level timestamp in Step 12.](EVIDENCE.md#step-12-timestamp-test)
- Test leaf certificates are issued at container startup with one-day validity.
  Native `docker-device-mgt-service-test/native-platform/certs.sh:137` and collector
  `docker-device-mgt-service-test/mock-xconf/certs.sh:37` delegate to
  `/etc/pki/scripts/generate_test_rdk_certs.sh`. In both images,
  `/etc/pki/scripts/create_leaf_cert.sh:95` sets `VALIDITY=1`; signing uses
  `-days "${validity}"` in `/etc/pki/scripts/cert_utils.sh:143`
  (default untracked signing; tracked CA signing also uses it at line 532).
  Renew by recreating both containers with the Compose down/up procedure above,
  then repeat readiness, CA refresh, backup, patch installation and T2 launch.
  Recreate the containers within ~20 hours before a demo. Both
  `openssl x509 -checkend 7200` checks must pass (2-hour margin).
  Do not bypass TLS validation.
- SIGTERM does not stop T2 in the observed shutdown path; use SIGKILL if it hangs.
- Loading a profile with a new hash rescans the full log, so grep counts jump.
